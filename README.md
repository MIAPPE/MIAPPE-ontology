# MIAPPE-ontology
## Modelling of Minimum Information About a Plant Phenotyping Experiment (MIAPPE) standard for description of phenotypic studies
This ontology can also be found in the [Agroportal](https://agroportal.eu/ontologies/PPEO) with full informations.

The owl file is the source of truth. The Turtle file (ttl) has been generated from owl for convinience.



Initialized on Lisbon MIAPPE RDFENO meeting 27-28.09.2017
